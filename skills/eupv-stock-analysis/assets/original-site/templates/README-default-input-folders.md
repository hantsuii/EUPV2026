# Default input files (fixed names)

Put default workbooks directly under `templates/` with these exact filenames:

- `inventory.xlsx`
- `daily_supply_plan.xlsx`
- `odp.xlsx`
- `orderfile_base.xlsx`

Notes:
- Uploaded files still have higher priority than repository defaults.
- Inventory and Daily Supply Plan are required sources.
- ODP and Orderfile Base are optional sources.
