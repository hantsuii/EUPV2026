Shipment Details 生成

根据本地脚本规则读取 Shipment Details 与 PICKUP 文件，匹配后写回指定工作表。

← 返回主页

输入参数

对应脚本参数：shipment_file
对应脚本参数：pickup_folder
对应脚本参数：sheet_name

处理逻辑（来自 Python 文件）

1) 读取与列名识别

  • Shipment Details 从首行读取表头。
  • PICKUP 文件自动尝试多种表头行（6/5/7/...）。
  • 按别名映射识别 TCL REF、B/L、SKU、Product、Container、Quantity、Pallets 等列。

2) Shipment 按 Pcs 展开

  • Pcs 为正整数时拆成多行，每行 1。
  • 保留原始件数到 Container Nos。
  • 拆分序号写入 ?? 列。

3) 与 PICKUP 匹配

  • 使用 4 键匹配：TCL REF + B/L + SKU + Product Name。
  • 匹配成功后回填 Container no / Quantity / Pallets。
  • 每条 PICKUP 记录仅使用一次。

4) 写回工作簿

  • 删除同名工作表（若已存在），再重建输出工作表。
  • 表头与单元格自动加边框、居中并自适应列宽。
  • 写回原 Shipment Details 文件。
