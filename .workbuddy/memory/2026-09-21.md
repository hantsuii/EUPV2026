### 改动内容
1. **品牌筛选位置调整**：总计 Dashboard 品牌筛选器从多选框改为单选下拉框，移至"2026年总览"标题上方，与下方 PV/ESS ASP 筛选器独立。地区详情弹窗的品牌筛选也相应移至弹窗顶部。
2. **客户分析品牌筛选**：新增 `customerBrandSel` 单选下拉框，位于工具栏第四列，筛选后所有客户视图同步更新。
3. **客户状态判断基准修改**：从"数据最近月份"改为"当前真实时间"。新增 `currentMonthStr()` 函数返回当前年和月，`customerReferenceMonth()` 直接返回当前月份。活跃=≤3个月内，沉睡=4–6个月，风险=>6个月。
4. **图表尺寸优化**：图表高度从 380px 降至 340px，窄屏适配降低至 300px/280px；产品图表网格比例从 1.45:0.9 调为 1.3:1；客户图表网格从 1.25:0.75 调为 1.15:0.85；chart-box 增加 overflow:hidden 防止超出边框。
5. **Target 品牌联动**：`normalizeTargets` 中新增 `brand` 字段读取 Target sheet 的 `Brand` 列。总计 Dashboard 品牌筛选时通过 `filterTargetsByDashboardBrand` 同步过滤 Target 行，地区详情弹窗通过 `filterTargetsByDetailBrand` 过滤。选中品牌后 KPI 卡的目标金额/数量、达成率以及季度进度表中的 BP 金额和达成率均按所选品牌的 Target 重新计算。
6. **ASP图表上下分区**：PV/ESS 的 ASP 折线图和数量柱状图放在同一张图中，用 Plotly domain 分区上下错开：上半区（domain 52%–100%）为 ASP 折线，下半区（domain 0%–45%）为数量柱状，共用 X 轴但不重叠。HTML 恢复为单个 chart 容器。
