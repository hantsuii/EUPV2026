## 2026-09-20 销售分析模块改动

### 修改文件
- `modules/sales/sales-change-analysis.js`
- `modules/sales/sales-change-analysis.html`
- `logic/daily-report-analysis-logic.md`

### 改动内容
1. **季度进度表**：从"只展示未结束季度"改为全年4个季度全部展示，默认折叠（只显示季度合计行），点击展开查看月明细。
2. **ASP图表**：PV ASP 和 ESS ASP 图表增加销售数量柱状图（双Y轴），折线=ASP（左轴），柱=数量（右轴）。
3. **地区看板筛选**：月份选择框高度从 size=6 改为 size=5 对齐；年份选择后月份自动筛减到对应年份；季度选择后月份自动筛减到对应季度。
4. **品牌筛选**：总计 Dashboard 和地区详情弹窗各新增品牌多选筛选器，筛选后所有 KPI/图表同步更新。
5. **层级列名兼容**：normalizeRows 中 level1 兼容 `Level1` 或 `Size Family`，level2 兼容 `Level2` 或 `Product Family`。
