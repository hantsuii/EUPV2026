# 组件预测与实际销售分析逻辑

## 数据源

- Country FCST：读取 `Conso`，仅保留 `Product Category = PV`。
- 本次提供的Country FCST作为历史预测基线；已结束月份的预测值冻结用于准确率回测，不要求按历史版本重建。
- EU DG销售：读取 `Order details`，仅保留 `Category = PV`。
- 历史实际仅使用 `Order Status2 = invoiced`；`confirm`单独展示。
- UPP和非欧洲地区不在当前FCST范围内，因此从本模块排除。
- Country FCST中Solarmarkt和Solexis的6条缺失地区记录按业务确认归入`France and Switzerland Region`。

## 产品聚合

聚合键由商业品牌、核心版型、电池片数、结构代码和CFP状态组成。

- TCL与SunPower分开。
- CFP与非CFP分开。
- 同一核心版型内合并相邻功率档。
- 不合并不同电池片数、结构代码、RES/COM或P7版本。
- 不采用FCST中已有的`Product Conso = exclude`作为排除依据；优先从原始型号重新识别。
- 无法识别的型号保留在`Unmapped`分类并在数据检查中显示。

## 历史准确率

只使用已结束且Country FCST包含的月份。

- WAPE = 月度绝对误差合计 / 实际合计
- 准确率 = max(0, 1 - WAPE)
- Bias = (FCST合计 - 实际合计) / 实际合计

## 销售速率

- 使用已结束月份的已开票MW。
- 1个月、3个月、6个月窗口均包含零销售月份。
- 全部地区先汇总MW，再除以月份数；不平均地区速率。
- 速率变化 = 最近窗口月均 / 前一窗口月均 - 1。

## 需求参考

- Bias修正系数 = 历史实际合计 / 历史FCST合计，限制在0.5至1.5之间。
- 预测可信度 = 历史准确率 × min(1, 可比较月份数 / 3)。
- 近期实际基准采用最近三个完整月加权月均，权重从早到晚为20%、30%、50%。
- 建议月均需求 = 预测可信度 × 未来三个月FCST月均 × Bias修正系数 + (1 - 预测可信度) × 近期实际基准。
- 产品地区样本不足时，依次回退到全部地区同产品、该地区全部PV、全部地区全部PV的历史准确率。

该需求值是透明的计划参考，不替代销售人员对具体项目、延期和取消风险的判断。
