# Default input files

Put repository-side default workbooks in this folder so users can run without uploading local files.

Expected filenames:

- `inventory_step1.xlsx` (required fallback)
- `daily_supply_plan.xlsx` (optional fallback)
- `eupv_odp_master.xlsx` (optional fallback)
- `orderfile_base.xlsx` (optional fallback)

Uploaded files take priority over repository defaults.
