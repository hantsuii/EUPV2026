使用说明（中文）

  • Inventory 文件来自 NewArk-Inventory 模块-Inventory List 导出。
  • Daily Supply Plan 文件来自 NewArk-Planning 模块-Supply Plan-选择起止月份-导出。
  • ODP 文件来自 SharePoint，请联系 Planning 或 PSR team 获取。
  • Orderfile Base 文件来自 NewArk-Report Center PV 模块-Orderfile Base-选择月份导出。
  • Inventory 和 Daily Supply Plan 为必选文件；ODP 和 Orderfile Base 为可选文件。

Instructions (English)

  • Inventory file comes from NewArk-Inventory module-Inventory List export.
  • Daily Supply Plan file comes from NewArk-Planning module-Supply Plan-select start and end months-export.
  • ODP file comes from SharePoint. Please contact the Planning or PSR team.
  • Orderfile Base file comes from NewArk-Report Center PV module-Orderfile Base-select month-export.
  • Inventory and Daily Supply Plan are required; ODP and Orderfile Base are optional.
