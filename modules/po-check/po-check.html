核验结果

本模块的核验规则

Approved

  • 按采购单号匹配 PO Check 的 SPTN-PVHK New Ark PO#。
  • 核对采购单 ETA、NewArk ETA PO、ETA for New Ark update。
  • 若更新 ETA 唯一且不同，结果文件会在更新后的采购单表中替换 ETA，并保留原值和建议。

Approving

  • 核对采购类型：Internal → Internal；Offshore → Offshore purchase；ongoing B/L change → Internal。
  • 核对 ETA 与 ETA for New Ark update。
  • 从 Customer Po 与 X 列（Note 后一列）清洗 TCL Reference，并按一个 PO 对应多条 PO Check 的情况比较集合。

SKU 与数量

  • 对 Approving PO，按 PO + SKU 汇总采购行的 Customer Model / Qty。
  • 与 PO Check 的 New Ark SKU / QUANTITY 汇总后逐 SKU 核对。
  • 同一 PO 的多条 PO Check 会合并，不会误判为重复。
