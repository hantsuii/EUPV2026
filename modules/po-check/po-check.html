本模块的核验规则

核验范围

  • 所有采购单 Status 和 Approval Status 均进入核验。
  • 每个 PO 都执行类型、两组 ETA、TCL Reference、SKU 和数量核验。

ETA 与输出

  • 按采购单号匹配 PO Check 的 SPTN-PVHK New Ark PO#。
  • 核对采购单 ETA、NewArk ETA PO、ETA for New Ark update。
  • 下载文件 PO Details 的 ETA 始终使用原始采购单值，建议 ETA 只在核验结果中展示。

明细核验

  • 核对采购类型映射，并显示 ODP 的 SKU 和 Model。
  • 从 Customer Po 与 X 列清洗 TCL Reference，并比较完整集合。
  • 按 PO + SKU 汇总 Customer Model / Qty，与 PO Check 汇总数量核对。
